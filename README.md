# Terravise

## 🌍 About The Project

### What is Terravise?

**Terravise** is an intelligent, field-ready geotechnical platform built natively for Apple Silicon (iPadOS). It transforms conventional Cone Penetration Testing (CPT / *Sondir*) campaigns from rigid, blind drilling schedules into an adaptive, data-driven exploration process.

In traditional geotechnical engineering, site investigations rely on rigid uniform grids (e.g., drilling a borehole every 25–50 meters). This creates a costly engineering paradox:

1. **In uniform soil**, rigid grids cause severe **over-drilling**, burning budget and weeks of rig time on redundant soundings.
2. **In complex soil**, rigid grids leave **critical blind spots**, failing to detect dipping bedrock, washouts, or soft sensitive clay lenses between boreholes.
3. **Stopping decisions are arbitrary**, traditionally dictated by depleted budgets or arbitrary contract counts rather than mathematical site understanding.

Terravise solves this by running deep generative models (**SchemaGAN V4.2**) and reinforcement learning (**DQN V4.6-A**) directly on-device to actively guide drilling *while it happens in the field*.
